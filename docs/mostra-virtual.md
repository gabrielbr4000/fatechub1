# Mostra Virtual — FATECHUB

**Frase de destaque:** Uma solução para uma comunicação mais centralizada e eficiente.

**Resumo:** O FatecHub é um projeto desenvolvido por dois estudantes da Fatec com o objetivo de implementar uma solução para o problema de comunicação descentralizada da faculdade. O projeto visa ter um messenger próprio, um sistema de mural com novidades, um sistema de turmas para comportar as atividades dos professores e todos os outros serviços oferecidos pela faculdade em um único local para que não haja quaisquer tipo de ruído nesse comunicação.
