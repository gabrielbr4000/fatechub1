# Manual do Usuário — FATECHUB

## Para USUARIOS

### Como criar meu perfil
1. Clique no botão cadastrar e selecione a opção desejadas.
2. Preencha suas informações referentes ao seu curso/trabalhos.
3. Finalize o cadastro.
[`images/print_cadastro.png`]

## Para ALUNOS

### Como enviar uma atividade feita
1. Faça login.
2. Vá até a seção de turmas e clique no botão de atividades.
3. Escolha a atividade certa.
4. Envie o arquivo e finalize.
[`images/print_atividades.png`]

### Como acessar o material da aula
1. Faça login.
2. Vá até a seção de turmas e clique na turma de interesse.
3. Escolha a opção arquivos.
4. Clique no material desejado para baixar.
[`images/print_arquivos.png`]

## Para PROFESSORES

### Como publicar tarefa
1. Faça login.
2. Vá até a seção de turmas e clique na turma desejada.
3. Clique no botão de atividades e no botão de "+" no canto inferior direito da tela.
4. Preencha o formulário, adicione os documentos/arquivos e finalize.
[`images/print_atividades_formulario.png`]

### Como publicar material de aula
1. Faça login.
2. Vá até a seção de turmas e clique na turma desejada.
3. Clique no botão de arquivos.
4. Clique em "Nova pasta" para criar uma nova pasta para o material e entre nela (opcional).
5. Clique em "Enviar arquivo" e escolha o arquivo no seu dispositivo.
[`images/print_arquivos_publicar.png`]

## Para COORDENADORES

### Como publicar no mural
1. Faça login.
2. Clique no "+" no canto superior direito no mural de novidades.
3. Preencha o formulário e envie uma imagem.
[`images/print_publicar_mural.png`]

### Como mudar o arquivo do calendário academico
1. Faça login.
2. Clique no "+" no canto superior direito no botão do calendário.
3. Escolha a opção apagar calendário para apagar o antigo (Opcional).
4. Escolha a opção adicionar calendário para enviar o novo.
[`images/print_calendario.png`]

## Perguntas frequentes
**Não encontro nenhuma turma do meu semestre, o que eu posso fazer?**
As turmas dos alunos cadastrados são referentes ao semestre e o curso escolhido durante o cadastro. Caso o semestre ou o curso escolhido não seja o correto, será necessário criar outra conta.

**Posso editar uma atividade que eu enviei?**
Você pode sim cancelar o envio para reenviar depois. Basta ir na atividade e selecionar a opção "Cancelar envio".
